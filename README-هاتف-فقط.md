# بناء تطبيق مصروفي من الهاتف فقط

لا تحتاج إلى كمبيوتر. سيتم بناء ملف APK على خوادم GitHub Actions.

## الخطوات
1. نزّل ZIP وفك ضغطه باستخدام مدير الملفات في هاتفك.
2. افتح https://github.com من متصفح الهاتف وسجّل الدخول أو أنشئ حساباً.
3. أنشئ مستودعاً جديداً (New repository)، سمّه `masroofi` واجعله Private، ثم أنشئه.
4. داخل المستودع اختر Add file ثم Upload files.
5. ارفع **محتويات مجلد Masroofi** بعد فك الضغط، وليس ملف ZIP نفسه. يجب أن يظهر مجلد `.github` ضمن الملفات؛ إذا أخفاه مدير الملفات فعّل إظهار الملفات المخفية.
6. اضغط Commit changes.
7. افتح تبويب Actions، واختر Build Masroofi APK، ثم Run workflow.
8. انتظر حتى تنتهي العملية بعلامة خضراء، افتح عملية البناء، وانزل إلى Artifacts.
9. نزّل `Masroofi-debug-apk`، وفك ضغطه، ثم افتح `app-debug.apk` وثبّته. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

## ملاحظات
- أول بناء يحتاج عدة دقائق وإنترنت.
- هذا APK تجريبي موقّع بمفتاح debug؛ لا تنشره كتطبيق تجاري قبل إعداد توقيع إصدار رسمي.
- بيانات التطبيق تبقى محلية على الهاتف؛ احرص على عدم حذف بيانات التطبيق دون نسخة احتياطية.
