# مصروفي – Masroofi

تطبيق أندرويد أولي لتسجيل المصروفات والإيرادات محلياً دون اتصال بالإنترنت.

## المزايا الحالية
- تخزين دائم محلي عبر SQLite.
- تسجيل المصروف أو الإيراد مع المبلغ والعملة والتصنيف والملاحظة والتاريخ.
- عملات متعددة، مع عرض رصيد مستقل لكل عملة (لا يتم جمع عملات مختلفة أو تحويلها تلقائياً).
- سجل عمليات وحذف عملية.
- واجهة عربية واتجاه يدعم RTL.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `Masroofi` في Android Studio.
3. انتظر مزامنة Gradle، ثم اختر Run لتثبيته على هاتف أندرويد أو محاكي.

المتطلبات: Android Studio حديث، JDK 17، واتصال إنترنت أول مرة لتنزيل أدوات البناء والمكتبات. بعد تثبيت التطبيق، تسجيل المصاريف وعرضها يعملان دون إنترنت.

## ملاحظات
هذه نسخة أولية 1.0. لا تتضمن حالياً تحويل أسعار الصرف، تصدير Excel/PDF، قفل التطبيق، أو نسخاً احتياطياً خارجياً. البيانات محفوظة داخل مساحة التطبيق على الجهاز؛ حذف التطبيق قد يؤدي إلى حذفها.
